## 重要規則

### Visible 欄位

```text
visible = true
```

代表欄位會出現在 Table List。

```text
visible = false
```

代表欄位不會出現在 Table List。

但即使 `visible = false`：

- Add Form 仍可顯示欄位；
- Edit Form 仍可顯示欄位；
- 資料庫欄位仍然存在；
- 不可因為不顯示而刪除欄位。

### 最多 6 欄

每張 Table 的 List 預設最多 6 個欄位為 `visible = true`。

如果使用者嘗試選第 7 個：

```text
顯示欄位最多只可選擇 6 個。
Maximum 6 visible columns are allowed.
最多只能选择 6 个显示字段。
```

不過這裡要特別確認：`TxId` 和 `Disable` 是否必定算入這 6 欄。我建議：

```text
TxId：固定顯示，不計入 6 欄限制
Disable／狀態：可由 UI 版面設定決定，計入 6 欄限制
```

如果你不同意，之後可以改成所有欄位包括 TxId 都計入 6 欄。

### 排序

每張 Table List 有兩種排序概念，應分開：

1. **資料行排序**
   - 預設：`TxId DESC`
   - 之後可按其他欄位升序／降序。
2. **欄位顯示順序**
   - 由 Drag 或上下箭頭決定。
   - 只影響欄位從左至右的排列。

欄位設定中的：

```text
升序／降序
```

我理解為該欄位的**預設資料排序方向**，不是欄位顯示順序。

## Disable 規則與 UI 設定

你之前要求所有 Table 都有 `Disable` flag：

```text
Disable = false → 顯示「失效」
Disable = true  → 顯示「啟用」
```

因此 `ui_table_settings` 和 `ui_table_columns` 本身也應有：

```text

```

但要區分兩個概念：

| 欄位 | 用途 |
|---|---|
| `disable` | 這筆設定資料是否失效 |
| `visible` | 欄位是否顯示在 List |
| `zebra_enabled` | List 是否使用間隔行底色 |
| `sort_direction` | 預設資料排序方向 |
| `display_order` | 欄位顯示位置 |

## UI 設定中的間隔行底色

你提供的畫面有：

```text

[✓] 列表間隔行底色

```

RoboArm 應支援：

- Checkbox：啟用／停用 Zebra rows。
- Color dropdown：至少提供：
  - 淺藍
  - 淺灰
  - 淺綠
  - 淺黃
- 預設：
  - `zebra_enabled = true`
  - `zebra_color = light_blue`

List 顯示時：

```css
tr:nth-child(even) {
    background-color: var(--zebra-color);
}
```

不可將顏色 hard-code；顏色名稱亦應經 Translation key 處理。
